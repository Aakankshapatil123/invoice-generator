# Invoice Builder

A responsive invoice  generation application built using React JS and Tailwind CSS.

## Features
- Add Client information
- Edit and delete items
- Automatic Subtotal and tax calculation
- Download invoice as PDF
- Responsive UI design

## Techstacks

- React JS
- Tailwind CSS
- React Hooks
- html2pdf.js

## Build

 npm run dev

## Deployment

Deployed using Netlify
